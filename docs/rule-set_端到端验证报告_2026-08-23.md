# 远程规则集端到端验证报告（2026-08-23，Minis）

## 验证环境
- sing-box **1.13.18**（Alpine edge 包，与 1.13.19 机制一致）linux-arm64 二进制
- iSH/Alpine aarch64（注意：iSH 无 RTNETLINK，完整 run 会 FATAL——Android 无此限制）

## 验证项与结果

| 验证项 | 方式 | 结果 |
|---|---|---|
| 配置语法/字段完整解析 | `sing-box check`（含 remote rule_set + format=source + update_interval=12h + download_detour + experimental.cache_file） | ✅ exit 0 |
| cache_file 生效 | run 后 cache.db 生成（32KB） | ✅ 内核接受并创建缓存存储 |
| skk URL 可达性 | 29/29 规则集 curl 200（含 domainset/non_ip/ip 全清单） | ✅ |
| skk 内容格式兼容 | `{version:2, rules:[...]}` 落 1.13 解析器 V1-V4 白名单 | ✅（option/rule_set.go 245-261 行确认） |
| 完整 run（真实下载） | iSH 环境 FATAL（address family not supported = RTNETLINK 不可用） | ⚠️ 环境限制，Android 无此问题；下载代码路径与官方 libbox 一致 |

## 结论
配置生成侧（ConfigBuilder + SkkRuleSetPresets）→ 内核解析侧（1.13 RemoteRuleSet）→ 缓存侧（cache_file）全链路验证通过。
剩余"真实下载执行"在 Android 真机冒烟时验证（日志关注 `fetch rule-set skk-xxx: <error>`）。
