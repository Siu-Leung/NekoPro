# 分组 DNS、入口导出与地址隐私

## 生效顺序

手填或手选的「节点域名 DNS」优先于同一订阅快照的自动采纳结果。候选页用原订阅 URL 请求 Clash Meta 格式，只分析响应，不访问其中的解析器；UA 无法强制服务返回完整配置。若只返回 `proxies`，导入包含 `dns` 的配置或手填地址，不从订阅名称、节点域名或 `hosts` 猜测地址。

自动采纳优先使用显式、合法且可移植的 `proxy-server-nameserver`。只有 `dns.enable` 开启、回环项确实指向该配置自己的监听、且 `nameserver` 全部是同一私有 UUID 路径的 HTTPS 端点时才视为镜像。不同域名与端口允许；不采用普通网站 DNS。刷新失败时保留原快照。

所有内置节点拨号使用其所属组的 resolver。多个端点由核心串行尝试，同组内超时/服务错误切换，正常答复（包括 NXDOMAIN）终止。不会为了探测未知域名去查询公网解析器，也不会把别组节点的 DNS 当后备。组解析器的服务域名仍需要直连 DNS 引导。

## 卡片和导出

- 卡片的入口地址指配置 IP 或当前/上次检测的 DNS 答案，不等于已有连接的远端地址。出口地址是隔离测速盒经该节点访问检测服务获得的结果，不读取手机物理出口。链式、外接插件或无从证明结果时，卡片不显示出口。
- 「检测入口/出口 IP」由用户点击并确认；公网地址和出口探测请求由 `api.ip.sb` 处理。滚动列表不会自动查询。截图开关只遮蔽卡片显示，不改变编辑页、日志、剪贴板或明确发起的导出。
- 单节点链接、二维码、节点配置及整组链接导出通过已配置的组 HTTPS DoH 查询，不使用卡片缓存或 ASN 服务。批量一次操作中同域名共用答案。仅修改导出副本；保留证书和协议握手身份。若协议参数不可保真或解析失败，保留原域名并提示。节点链接不包含 DoH URL，导出的完整 JSON 若包含尚未固定的其他分组节点，相关解析器仍由配置生成规则决定。
- IP 是按当前网络和解析结果生成的快照，入口变动时重新导出。需要自定义 TLS/Host 的节点宜使用保留全部参数的通用链接。
